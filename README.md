# Zoo Explorer (Web App)

โครงสร้างโปรเจกต์ (เรียงตามลำดับการใช้งานจริง 01 → 10):

```
zoo-app/
├── 01-login/              -> หน้า Login ด้วย LINE (LIFF)
├── 02-welcome/             -> หน้าต้อนรับ (Welcome / Onboarding)
├── 03-home/                -> หน้า Zoo Passport (Progress + รายชื่อโซนสัตว์) + หน้ารายละเอียดโซนทั่วไป
├── 04-lion-zone/            -> หน้าแนะนำโซนสิงโต + ปุ่มเริ่มเกม
├── 05-mini-game/            -> มินิเกมจับคู่รอยเท้า (Lion Zone) มีจับเวลาและคะแนน
├── 06-stamp-received/       -> หน้าแจ้งว่าได้รับตราประทับ (หลังเล่นมินิเกมผ่าน)
├── 07-map/                  -> แผนที่สวนสัตว์ พร้อมหมุดของแต่ละโซน
├── 08-collection/           -> หน้ารวมตราประทับทั้งหมด (My Collection)
├── 09-reward/                -> หน้าฉลองเมื่อเก็บครบทุกโซน (Congratulations)
├── 10-profile/               -> หน้าโปรไฟล์ผู้เล่น + เมนูย่อย
└── assets/img/               -> โลโก้/รูปสัตว์/แผนที่/อวาตาร์ ใช้ร่วมกันทุกหน้า
```

เปิดไฟล์แต่ละหน้าได้ที่ `xx-ชื่อหน้า/index.html` โดยเริ่มจาก `01-login/index.html`

## ลำดับการใช้งาน (ตรงกับผังที่ออกแบบไว้)

1. **01-login** — เข้าสวนสัตว์ / เพิ่มเพื่อน LINE OA
2. **02-welcome** — หน้าต้อนรับ กดปุ่ม "เริ่มต้นการผจญภัย"
3. **03-home** — หน้า Zoo Passport แสดงความคืบหน้า 0–6 ตราประทับ กดแต่ละโซนเพื่อดูรายละเอียด
4. **04-lion-zone** — ตัวอย่างหน้ารายละเอียดโซน (สิงโต) กดปุ่ม "เริ่มเกม"
5. **05-mini-game** — มินิเกมจับคู่รอยเท้า/สิงโต จับเวลา 30 วินาที เล่นผ่านแล้วไปหน้าถัดไป
6. **06-stamp-received** — แจ้งว่าได้รับตราประทับ Lion Zone แล้ว กด "ดูพาสปอร์ต" กลับไปหน้า 03
7. **07-map** — แผนที่สวนสัตว์ แตะหมุดแต่ละโซน (ตอนนี้หมุดสิงโตลิงก์ไปหน้า 04 จริง ส่วนโซนอื่นยังพาไปหน้ารายชื่อโซนก่อน)
8. **08-collection** — ดูภาพรวมตราประทับทั้งหมด เข้าได้จากหน้าโปรไฟล์
9. **09-reward** — หน้าเมื่อเก็บครบทุกโซน (ตอนนี้เป็นหน้าตัวอย่างแบบ standalone ยังไม่ผูกกับเงื่อนไข "ครบ 6/6" อัตโนมัติ)
10. **10-profile** — โปรไฟล์ผู้เล่น มีสถิติ Stamps/Points และเมนู My Collection / History / How to Play / Settings

เมนูล่าง (Passport / Map / Profile) ในหน้า 03-home และ 10-profile เชื่อมลิงก์ถึงกันแล้ว

## สิ่งที่เพิ่มในรอบนี้
- สร้างหน้าใหม่ 6 หน้า (05–10) ตามผังภาพรวมการใช้งานที่ให้มา: Mini Game, Stamp Received, Map, Collection, Reward, Profile
- ทุกหน้าใหม่ใช้กรอบมือถือ (`.phone`) และโทนสี/ฟอนต์เดียวกับหน้า 04-lion-zone (เขียวป่า/ทอง/ครีม) เพื่อให้ดูเป็นชุดเดียวกัน
- เชื่อมลิงก์ปุ่ม "เริ่มเกม" ในหน้า 04-lion-zone ให้ไปที่หน้า 05-mini-game จริง (จากเดิมเป็นแค่ alert)
- อัปเดตเมนูล่างในหน้า 03-home ให้มีชื่อกำกับ (Passport / Map / Profile) และลิงก์ไปหน้า 07-map, 10-profile จริง

## ข้อจำกัดที่ควรรู้ (สำหรับพัฒนาต่อ)
- แต่ละหน้ายังทำงานแบบแยกไฟล์กัน ไม่มีการเก็บสถานะร่วม (เช่น จำนวนตราประทับ) ข้ามหน้า เพราะยังไม่ได้ต่อ localStorage หรือฐานข้อมูล — ตอนนี้ตัวเลขในหน้า Collection/Profile/Reward เป็นค่าตัวอย่าง (mock data) ที่ตั้งไว้ตรงๆ ในโค้ด
- หน้า 07-map เชื่อมโซนสิงโตไปหน้า 04 จริง ส่วนโซนอื่น (ช้าง ยีราฟ เพนกวิน แพนด้า ลิง) ยังไม่มีหน้ารายละเอียด/มินิเกมของตัวเอง ต้องทำเพิ่มทีหลังตามแพทเทิร์นของ 04-lion-zone + 05-mini-game
- หน้า 10-profile เมนู History / How to Play / Settings ยังเป็นแค่ alert ชั่วคราว ยังไม่ได้สร้างหน้าจริง
- ถ้าต้องการให้ตราประทับ/คะแนน/ความคืบหน้าซิงค์กันจริงข้ามหน้า แนะนำให้เพิ่ม `localStorage` (เก็บ object เดียว เช่น `zooProgress`) แล้วให้ทุกหน้าอ่าน/เขียนจากตรงนั้นแทนค่า mock ที่ตั้งในแต่ละไฟล์

## ประวัติการแก้ไขก่อนหน้า
- รูปภาพทั้งหมดเคยลิงก์ไปที่ Discord CDN (media.discordapp.net) ซึ่งมีพารามิเตอร์หมดอายุ (ex=...) ทำให้รูปเสียเมื่อเวลาผ่านไป — เปลี่ยนมาใช้ไฟล์ในโฟลเดอร์ assets/img/ แทนทั้งหมด
- ชื่อโฟลเดอร์เดิม (mian, next main, mian/next main ที่เป็นไฟล์ว่างเปล่า, Start Game) เปลี่ยนเป็นชื่อที่สื่อความหมายและเรียงตามลำดับการใช้งาน
- แก้ลิงก์ปุ่ม "เริ่มต้นการผจญภัย" ให้ชี้ไปที่ 03-home/index.html ที่ถูกต้อง
- แก้ HTML ที่ผิดพลาด เช่น link ที่ชี้ไปยังไฟล์ .html แทน .css, แท็ก body ซ้ำ, attribute class ซ้ำในปุ่มเดียว
- รูปในหน้า 04-lion-zone เดิมเป็นรูปสิงโตที่ไม่มีไฟล์แนบมาด้วย ใช้ lionlogo.png แทนไปก่อน แนะนำให้เปลี่ยนเป็นรูปจริงภายหลัง
